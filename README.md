🐍 Snake Game in C

A classic Snake Game developed using C programming and designed to run in a Windows console.

The player controls the snake, collects fruits, earns points, and tries to avoid collisions with the walls and its own tail.

🎮 Features

- Keyboard Controls: Move the snake using W, A, S, and D.
- Fruit Collection: Collect fruits ("*") to increase your score.
- Score System: Earn 10 points for every fruit collected.
- Growing Snake: The snake's tail grows as it collects fruits.
- Collision Detection: The game ends when the snake hits a wall or its own tail.
- Exit Option: Press X to exit the game.
- Console Interface: Play directly in a Windows console.

🕹️ Controls

Key| Action
W| Move Up
A| Move Left
S| Move Down
D| Move Right
X| Exit Game

🛠️ Technologies Used

- C Programming Language
- GCC Compiler
- Windows Console
- Standard C libraries and Windows-specific console functions

🚀 How to Run

Prerequisites

- Windows operating system
- GCC compiler installed and configured
- VS Code or another C editor

Steps

1. Clone or download this repository.

2. Open the project folder in VS Code.

3. Open the terminal.

4. Compile the program:
   
   gcc snake.c -o snake.exe

5. Run the game:
   
   .\snake.exe
